# Dionis — агент для Василия

Профиль Hermes Agent: личный помощник руководителя. Персона, базовый конфиг, набор скиллов.

## Установка

Полная пошаговая инструкция — в файле [`INSTALL.md`](INSTALL.md): что поставить,
откуда взять ключ, что и где менять.

Коротко:

```bash
hermes profile install <адрес этого репозитория> --alias --yes
```

Дальше:

1. Профиль попросит ключ API. Ключ свой, отдельный — авторский сюда не входит.
   После установки рядом появится `.env.EXAMPLE`; скопируй в `.env` и впиши ключ:

   ```
   cp ~/.hermes/profiles/vasily/.env.EXAMPLE ~/.hermes/profiles/vasily/.env
   # отредактируй: HERMES_CUSTOM_POLZA_AI_API_KEY=<свой ключ>
   ```

2. Запуск: `vasily chat` (или `hermes -p vasily chat`).

## Что внутри

| Путь | Что это |
|---|---|
| `distribution.yaml` | манифест: имя, версия, требуемые переменные окружения |
| `SOUL.md` | персона агента (правится под владельца) |
| `config.yaml` | модель, провайдер (Polza.ai), инструменты, язык — **без ключей** |
| `skills/` | 58 штатных скиллов Hermes (документы, таблицы, PDF, поиск, почта, заметки, код) |
| `.env.template` | шаблон `.env`, устанавливается как `.env.EXAMPLE` |

Ключ API живёт только в `.env` и в репозиторий не попадает: в `config.yaml` стоит
`key_env: HERMES_CUSTOM_POLZA_AI_API_KEY`, то есть имя переменной, а не значение.

## Что не входит

- API-ключи, `auth.json`, пароли dashboard — только свои, локальные.
- MCP-серверы (Revit, AutoCAD и прочее) — не подключены, ставятся отдельно под свои задачи.
- SSH-бэкенд, cron-задачи, память и история автора.

## Обновление

```bash
hermes profile update vasily
```

Обновляются `SOUL.md`, `config.yaml`, `skills/`. Файлы пользователя (`.env`, память,
история, сессии) не трогаются. Если `config.yaml` правился локально, он сохраняется —
сбросить к версии из репозитория можно флагом `--force-config`.

## MCP (по желанию)

Добавляется уже в установленном профиле:

```bash
hermes -p vasily mcp add <имя> --command <команда>
hermes -p vasily mcp catalog          # посмотреть, что есть в каталоге
```
